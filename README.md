# Multi Domain Insight Engine 🚀

This repository showcases a series of advanced Data Engineering and Exploratory Data Analysis (EDA) projects across three major domains: **Mobile Applications**, **Open-Source Software Development**, and **Global Streaming Entertainment**.

The project transforms raw, unstructured data into actionable business intelligence using Python's robust data science stack.

![alt text](<Architecture.png>)

## 📂 Project Overview

This repository is divided into three core analysis modules:

### 1. Google Play Store & Sentiment Analysis 📱
* **Focus:** Market research of 10,000+ Android apps.
* **Key Tasks:** - Data cleaning (handling special characters in `Installs` and `Price`).
    - Analyzing distribution across 33 app categories.
    - Merging user reviews for sentiment polarity analysis.
* **Insight:** Identifying high-growth categories and correlating user ratings with sentiment scores.

### 2. GitHub Ecosystem & Developer Trends 🛠️
* **Focus:** Analyzing the evolution of the Scala programming language via GitHub history.
* **Key Tasks:** - Processing historical pull request data (2011–2018).
    - Tracking file-level changes to identify "hotspots" in the codebase.
    - Visualizing contribution frequency to identify key project maintainers.
* **Insight:** Understanding the velocity of open-source development and developer retention.

### 3. Netflix Content Strategy Analytics 🎬
* **Focus:** Exploring the shift in global content distribution and duration.
* - **Key Tasks:** - Filtering and segmenting Movies vs. TV Shows.
    - Genre-based clustering to identify content saturation.
    - Analyzing the hypothesis: *"Are movie durations getting shorter over time?"*
* **Insight:** Mapping Netflix’s content evolution from 1990 to 2021.

## 🛠️ Tech Stack & Tools

- **Language:** Python 3.13.9
- **Libraries:** - `Pandas` & `NumPy` (Data Manipulation)
    - `Matplotlib` & `Seaborn` (Static Visualization)
    - `Plotly` (Interactive Dashboarding)
- **Environment:** Jupyter Notebooks / Dockerized Ingestion Scripts
